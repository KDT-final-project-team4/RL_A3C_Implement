03. 핵심 수학 기호 및 용어 사전 (Terminology)

A3C 논문의 수식을 이해하기 위해 반드시 알아야 할 핵심 변수들입니다.

환경 & 상호작용

  • $s_t$ 상태 (State): 에이전트가 관찰하는 화면
  • $a_t$ 행동 (Action): 에이전트의 선택
  • $r_{t}$ 보상 (Reward): 행동 직후 받는 즉각적 점수
  • $\gamma$ 할인율 (Gamma): 미래 보상의 현재 가치

에이전트의 뇌 (신경망)

  • $\pi_\theta$ 정책 (Policy): Actor 네트워크.
    상태 $s$에서 행동 $a$를 할 확률.
    ($\theta$: 신경망 파라미터)
  • $V_{\theta_v}$ 가치 (Value): Critic 네트워크.
    상태 $s$의 평균 기대 점수.
    ($\theta_v$: 가치망 파라미터)
  • $R$ 누적 보상 (Return): n-step 후의 미래 가치까지 포함한 총합 추정치.

학습 지표

  • $A_t$ 어드밴티지 (Advantage): 특정 행동이 평균 기대치($V$)보다 얼마나 더 좋은지.
  • $H$ 엔트로피 (Entropy): 정책의 무작위성(불확실성). 클수록 탐험을 많이 함.
  • $\nabla$ 기울기 (Gradient): 파라미터 업데이트 방향.

09. Lock-free 최적화 (Hogwild! 알고리즘)

충돌 위험? (Race Condition)

원래 프로그래밍에서는 여러 스레드가 하나의 변수(Global Network)를 동시에 수정하면 데이터가 깨지므로 '자물쇠(Lock)'를 채웁니다. 하지만 Lock을 걸면 속도가 느려집니다.

Hogwild! 기법의 도입

A3C는 딥러닝의 특성(수많은 파라미터 중 소수만 업데이트됨)을 활용해 자물쇠(Lock)를 아예 없애버렸습니다. 가끔 충돌해서 값이 조금 깨지더라도(Noise), 딥러닝 특유의 강건함 덕분에 무시하고 더 빠른 속도로 수렴해버립니다!

10. 왜 A'3'C 인가? 이름의 기원

A

Asynchronous (비동기)

여러 개의 워커(Agent)가 락(Lock) 없이 병렬로 동시에 환경과 상호작용하며 학습합니다.

A

Advantage (어드밴티지)

절대적인 총 보상($R$)이 아닌, 평균 기대치 대비 얼마나 더 좋은지($Q-V$)를 사용하여 학습 분산을 줄입니다.

AC

Actor-Critic (배우-평론가)

행동을 결정하는 Actor와 그 행동을 평가하는 Critic 네트워크를 동시에 사용하여 빠르고 안정적으로 수렴합니다.

3. Deep Dive into A3C Math

11. 1-Step의 한계와 n-Step Return의 도입

미래를 예측할 때, 몇 발자국 앞까지 내다볼 것인가?

1-Step TD (기존 방식)

바로 다음 스텝 1개만 보고 보상을 합산합니다. 분산(Variance)은 적지만 편향(Bias)이 심하고 보상 전파가 아주 느립니다.

n-Step Return (A3C 방식)

앞으로 n번(예: 5스텝) 동안 행동을 쭉 해보고, 그동안 받은 진짜 보상들을 더한 뒤 마지막에만 가치($V$) 예측치를 붙입니다. 보상 전파가 훨씬 빨라집니다!

12. n-Step Return 수식과 Advantage

n번의 스텝을 진행한 뒤, 목표 가치(Return)와 어드밴티지(Advantage)를 계산합니다.

n-step Return (목표 점수)
$$ R_t = \sum_{i=0}^{k-1} \gamma^i r_{t+i} + \gamma^k V_{\theta_v}(s_{t+k}) $$
A3C Advantage Estimate
$$ A(s_t, a_t) = R_t - V_{\theta_v}(s_t) $$

"내가 n스텝 동안 직접 뛰어보고 예상한 진짜 목표 점수($R_t$)에서, 처음 출발할 때 평론가가 예상했던 기대 점수($V(s_t)$)를 뺀 값"

3. Deep Dive into A3C Math

13. A3C의 3가지 Loss Function 완벽 해부

워커(Worker)는 자신이 모은 경험(n-step)으로 다음 세 가지의 기울기(Gradient)를 계산하여 글로벌 뇌를 업데이트합니다.

1. Policy Update
(Actor) $$ d\theta \leftarrow d\theta + \nabla_{\theta'} \log \pi_{\theta'}(a_t|s_t) \cdot A(s_t, a_t) $$
2. Value Update
(Critic) $$ d\theta_v \leftarrow d\theta_v + \partial \frac{(R_t - V_{\theta_v}(s_t))^2}{\partial \theta_v} $$
3. Entropy Bonus
(Exploration) $$ d\theta \leftarrow d\theta + c \cdot \nabla_{\theta'} H(\pi_{\theta'}(s_t)) $$
3. Deep Dive into A3C Math

14. Entropy Bonus: 탐험(Exploration)의 강제

A3C 논문이 안정적인 학습을 위해 도입한 비장의 무기입니다.

조기 수렴(Premature Convergence) 방지

에이전트가 운 좋게 10점을 받는 행동을 찾으면, 그 행동 확률을 100%로 굳혀버리고 더 이상 탐험하지 않습니다(Local Minima).

이를 막기 위해 "행동 확률 분포가 평평할수록(불확실할수록 = 엔트로피가 높을수록) 보너스 점수를 주는 수식($\beta \nabla H$)"을 추가하여, 끝까지 다양한 행동을 시도하도록 강제합니다.

엔트로피 낮음 (보너스 0)
1개 행동만 고집
VS
엔트로피 높음 (보너스 지급!)
고르게 고민 중

18. 스케일링의 마법 (Linear Speedup)

워커(Thread) 수를 늘릴수록 학습 속도가 정비례(Linear)하여 빨라집니다.

일반적으로 멀티스레드 프로그래밍은 Lock 걸림 현상 때문에 코어 수를 늘린다고 속도가 정비례해서 오르지 않습니다.

하지만 A3C는 Lock-free 비동기 업데이트 구조와 탐험의 다양성(여러 워커가 각기 다른 경험 수집) 시너지 덕분에 스레드가 늘어나는 만큼 거의 완벽하게 학습 속도가 비례해서 단축되는 기적을 보여주었습니다. (Super-linear 현상도 관찰됨)

19. A3C에서 A2C로의 진화 (Legacy)

A3C의 위대함

'비동기 병렬 처리 + n-step Return + Actor-Critic + Entropy' 라는 현대 강화학습의 마스터피스 조합을 완성해 냈습니다.

그러나 다시 동기식(A2C)으로...

CPU 중심의 A3C는 훗날 모델이 거대해지면서 한계에 부딪힙니다. OpenAI 연구진은 이 위대한 A3C 구조를 그대로 유지하되, 비동기(Asynchronous)를 동기(Synchronous)로 바꿔 GPU의 배치(Batch) 처리 효율을 극대화한 A2C를 발표하게 되고, 이것이 PPO로 이어집니다.
